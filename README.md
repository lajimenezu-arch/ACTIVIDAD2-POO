Descripción de los Ejercicios

Este repositorio contiene la solución a los 5 ejercicios prácticos asignados en la Actividad 2, desarrollados en el lenguaje de programación Python bajo el paradigma de Programación Orientada a Objetos:

1. **Ejercicio 2.1 - Clase Persona:** Modelado básico de una entidad con atributos de identidad e impresión de datos personales.
2. **Ejercicio 2.2 - Clase Planeta:** Definición de propiedades físicas, cálculo de densidad ($\rho = m/V$), evaluación de ubicación en el sistema solar exterior y uso de enumeraciones (`TipoPlaneta`).
3. **Ejercicio 2.3 - Clase Automóvil:** Métodos para simulación de aceleración, desaceleración, frenado, cálculo de tiempo estimado de llegada ($t = d/v$) e integración de enumeraciones (`TipoCombustible`, `TipoAutomovil`).
4. **Ejercicio 2.4 - Clase CuentaBancaria:** Encapsulamiento de saldo contable, operaciones de consignación y retiro con validación de fondos, e integración del enum `TipoCuenta`.
5. **Ejercicio 2.5 - Clase Círculo:** Modelado geométrico con control de accesores mediante `@property` para validar que el radio no sea negativo, junto con los cálculos de área ($A = \pi \cdot r^2$) y perímetro ($P = 2 \cdot \pi \cdot r$).
